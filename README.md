## The entry

**Ghosting**

One word for your Wi-Fi. Home Wi-Fi does not merely drop out — it
vanishes mid-sentence, mid-call, mid-download, with no warning and no
explanation, exactly like a date who ghosts you. It is there, it is
gone, and it never tells you why.

The joke lands at once, it is true of every home network anyone has
ever lived with, and it works as a network name on its own: spotting
"Ghosting" in a list of SSIDs needs no footnote. It is the one word
everyone reaches for only after the third dropped call — and the one
nobody else thought to submit first.

## How it works

`main.py` writes the single word `Ghosting` to `/output/entry.txt`
(8 characters, UTF-8, one word — inside the gate's 1–20 character
limit). No network, no input data, no secrets: the program is fully
deterministic and self-contained.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
